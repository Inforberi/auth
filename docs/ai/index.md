# Карта проекта

Текущий корректирующий аудит domain/service/repository/transport/app и его последовательность — [границы слоёв](../planning/layer-boundaries-audit.md). Это план устранения конкретных находок, не отметка о завершённом рефакторинге.

Начать с [текущего шага](current-task.md), затем выбрать нужную строку ниже. Это навигация, не список обязательного чтения: статусы — в плане, поведение — в коде, доказательства — в history. Правила — [AGENTS.md](../../AGENTS.md).

Пути к исходникам относительно корня репозитория; Auth = `internal/auth`, Project = `internal/admin/projects`.

Согласованное целевое дерево MP6R — в [архитектуре](../architecture.md), карта переносов — в [плане рефакторинга](../planning/readability-refactor.md). R2 sandbox закоммичен; в R3 backend-пакеты перенесены в admin/administrators и admin/projects, R3 принят Luna. R7 завершает общую сборку процесса и проектные адаптеры; актуальная приёмка — в текущей заметке.

Конкретные владельцы и границы переноса зафиксированы в [карте R1 от2 ноября](../planning/readability-refactor.md#r1-карта-переносов-и-контрактов--2-ноября-2026); её завершение не означает, что целевые пакеты уже существуют или проверены исполнением.
