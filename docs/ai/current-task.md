- Нагрузочный mixed/multi-instance прогон 6.8b оставлен на конец перед release. Оптимизация входит в реализацию каждой фичи; SQL-only benchmark не является API capacity/RPS.
- Проверки 5.7c: formatter, task check (unit/HTTP/env tests и lint 0 issues), Swagger generation/drift; race service/config/router, затем service после retry-оптимизации. Полный disposable PostgreSQL 18.6 suite up/down/up после оптимизации — 5.772s; целевые temporary-password сценарии повторены после уточнения pending lock. 16 parallel provision/reissue дают один plaintext, 16 login — одну authority, 16 complete — один успех; expiry/cleanup/stale snapshot/block/delete/bypass/race/audit rollback и отсутствие email verification.
- Рабочая БД/env/secrets не менялись. Расширена только исходная 000001 up/down; уже применённую схему не сбрасывать. Тестовый контейнер удалён с синтетическими данными. Это не browser/operator UI, Redis fault E2E нового flow или production/load acceptance.
