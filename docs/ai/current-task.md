# Текущий шаг

U2 standalone зафиксирован коммитом `3e430379`. Целевые проверки сборки, миграции 000009, прав, ENV, Swagger и линтера прошли. [Лог линтера](/private/tmp/auth-u2-oplint-O2y8jt/lint.log).

U3 management в работе. Добавлена смена отображаемого имени проекта с контролем версии, транзакционным аудитом и повтором по operation ID. [Контракт](../features/platform-project-mutations.md#отображаемое-имя-проекта). Затронуты миграция platform 000003 и runtime grants.

Подготовлен API создания pending-аккаунта, блокировки, разблокировки и мягкого удаления пользователя проекта. Для ранее созданных проектных БД требуется Auth-миграция 000010 и узкие права runtime на аудит. К созданию добавлено приглашение через проектный outbox. Добавлена выдача временного пароля при создании аккаунта с одноразовым возвратом секрета. Подключены повторная выдача временного пароля и первичная запись неподтверждённого адреса для pending-аккаунтов без credentials. Добавлено управление операторами общей панели: приглашение, список, обновление полномочий и отзыв доступа. Требуется platform-миграция 000004 и обновление runtime grants. Добавлены проектные MFA и retention, редактирование обычных ролей и отдельное назначение или отзыв системного администратора. Подключено чтение и обновление SMTP, Google, Telegram OIDC и credentials Telegram-бота из общей панели. Подключена активация Telegram webhook из общей панели с использованием origin и секрета проекта. Добавлена проектная политика сроков новых браузерных сессий. Подключены сроки ссылок и credentials проекта. Добавлены лимиты входа по паролю, регистрации и сброса пароля, а также project frontend policy с проверкой Origin, CORS и ссылками. Подключены расширенные квоты операций. Добавлены заявка и статус подготовки для имеющегося executor и предварительная проверка удаления владельцем. Подключены исполнение заявки до ready и подтверждённое удаление проектной БД через существующий provisioner. Реализация U3 перед целевой приёмкой Luna. U3.1 backup/recovery расположен отдельным шагом плана. Критерии приёмки и оставшиеся этапы — в [плане U3](../planning/ui-management.md#u3-единое-управление-проектами-и-административными-действиями).
